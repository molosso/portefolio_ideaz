# Arcane Fan Experience

A responsive fan-made landing page inspired by the supplied Arcane design reference.

## Files
- `index.html` — page structure
- `style.css` — layout, colors, effects and responsive styles
- `script.js` — search, mobile menu and interactive mock video controls
- `assets/jinx.png` — Jinx artwork used throughout the page
- `assets/vi.png` — Vi artwork used throughout the page

## Add your images
Create an `assets` folder beside `index.html` and place your image files inside it. The filenames must match exactly: `jinx.png` and `vi.png`.

## Run locally
Open `index.html` in your browser.

## Deploy
Import this folder or repository into Netlify. This is a static site, so no build command is required.

## Notes
The video controls are visual demos and do not stream episodes. Use artwork and video links that you have permission to publish.
