# Portfolio Collection

A collection of web portfolios recreated from different design mockups. The mockups may be created by me, designed by a graphic designer, or found on Pinterest for inspiration.

Each portfolio is enhanced with animations, interactive elements, and custom styling to bring the designs to life.

## Features

- Multiple portfolio designs and visual styles
- Based on personal mockups, graphic designers' work, or Pinterest inspiration
- Custom animations and interactive effects
- Responsive layouts for desktop and mobile
- Built with only three files: HTML, CSS, and JavaScript
- No frameworks or complex dependencies
- Easy deployment with Netlify

## Technologies

- HTML5
- CSS3
- JavaScript

## Deployment

Each portfolio is built using three main files:

- `index.html`
- `style.css`
- `script.js`

The projects can be deployed directly to [Netlify](https://www.netlify.com/) by connecting the GitHub repository. No build command or additional configuration is required.

## Credits

Designs are based on my own mockups, graphic designers' work, or references found on Pinterest. Credit goes to the original creators where applicable.

## Purpose

To practice frontend development, explore different design styles, recreate visual concepts, and bring them to life with animations and interactive elements.
